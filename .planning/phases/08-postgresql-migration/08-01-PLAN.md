<description>Rewrite db.js to use pg-pool</description>
<read_first>
- backend/db.js
</read_first>
<action>
Rewrite `backend/db.js`.
Replace sql.js logic with `const { Pool } = require('pg');`.
Initialize `const pool = new Pool({ connectionString: process.env.DATABASE_URL })`.
Export a `query(text, params)` wrapper that calls `pool.query()`.
Since sql.js was synchronous, adapting `db.prepare(sql).all()` means the app routes need async `await db.query(sql, params)`. Export `query` as the new primary interface, and export `transaction` that accepts an async callback, running it with `pool.connect()`, `BEGIN`, `COMMIT`, `ROLLBACK`.
</action>
<acceptance_criteria>
- `backend/db.js` contains `require('pg')`
- `backend/db.js` contains `const pool = new Pool`
- `backend/db.js` contains `pool.query`
</acceptance_criteria>
</task>
