# Stack

## Runtime
- **Node.js**: >=20

## Backend
- **Framework**: Express.js
- **Database**: SQLite via `sql.js` (WebAssembly build for Node)
- **Validation**: Zod
- **Authentication**: JWT (JSON Web Tokens), bcryptjs
- **Logging**: Pino, Pino-HTTP, Pino-Pretty
- **Security**: Helmet, Express Rate Limit
- **Utilities**: Multer (File Uploads), Axios, Compression, CORS, Dotenv

## Frontend
- **Framework**: Next.js 16 (App Router)
- **Library**: React 19
- **State Management**: Zustand
- **Styling**: Tailwind CSS 4, CSS Modules
- **Analytics**: PostHog
- **Image Optimization**: Sharp

## Infrastructure
- **Package Manager**: NPM
- **Version Control**: Git
